# Study_File_Collector
The Study File Collector Tool is a user-friendly desktop application designed to automatically scan, identify, and organize files related to specific clinical studies or research projects — so you spend less time hunting and more time analyzing. The Version 2 (V2) of this tool also has a history/recent feature from which you can select the project/study which you worked previously instead of manually entering them everytime this makes things easier for the user.
